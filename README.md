# From Vibe Coding to Code: My Coding Practice

Today, AI tools allow us to develop many things much faster and more easily. I also use these tools throughout my learning and development process.

However, for a while, I have felt that **I have become too accustomed to vibe coding, and that it has reduced my practice of writing code on my own.**

For this reason, I created this repository to apply what I learn more independently and to practice coding regularly.

Here, I will share my data analysis work on different datasets and, as I progress, my own implementations of the topics I learn.

## 🎯 Purpose of This Repository

The purpose of this repository is not to create perfect projects or to prove that I can do everything without using AI.

My goal is to **take advantage of the convenience AI provides while continuing to improve my own coding and problem-solving skills.**

I want to write code, make mistakes, understand why those mistakes happen, and try to find solutions on my own when necessary.

Therefore, the work in this repository is primarily a **practice and learning process** for me.

I will continue updating this repository as I learn, experiment, and improve.
